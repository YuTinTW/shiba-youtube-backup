目前程式流程（靜態閱讀）：

1. GUI 檢查並正規化網址，發出讀取工作。
2. 背景程序檢查 FFmpeg、ffprobe、Deno，呼叫 yt-dlp 取得格式。
3. 使用者勾選格式後送出下載工作；核心重新讀取格式並檢查選取項目。
4. 每個項目使用儲存資料夾內的獨立 `.shiba-` 暫存目錄。
5. 影片與音訊分開下載，需要時用 FFmpeg `-c copy` 合併，再由 ffprobe 檢查必要串流。
6. 輸出以硬連結建立；不支援時改用 `xb` 排他建立及複製，同名則增加序號。
7. 事件經 stdout／佇列回 GUI；診斷文字寫至 `~/Library/Logs/ShibaStudio/diagnostic.log`。

補充：GUI 工作中會阻止正常關閉視窗；不等於已處理程序遭強制終止的清理。背景程序隔離也不等於權限沙箱。
