# 柴犬存檔室：檢查報告與設計提案

日期：2026-11-14。階段：程式檢查與介面概念預覽。尚未實作新介面或打包。
使用者訊息末尾為程式碼佔位文字，因此本次以專案內 `20261110_完整youtube影片存檔程式.py`（324 行）為準。原檔保持不變。

## 已查證：原始程式

完整閱讀並以 ast.parse 通過語法檢查，未啟動 GUI 或執行網路下載。

- tkinter：Python 的視窗介面模組，建立輸入框、按鈕、勾選框及捲動區；底層需要 Tcl/Tk。
- pytubefix.YouTube：第三方套件，用來讀取影片串流及下載；原碼沒有使用 yt-dlp。
- subprocess：Python 標準模組，執行外部 ffmpeg。
- os：Python 標準模組，處理資料夾與路徑。
- 列出 MP4 純影像，按解析度排序；列出所有純音訊。保留多選。
- 下載影像後，自動選取標示位元率最高的 MP4 音訊，以 ffmpeg 的串流複製模式合併成 MP4，不重新編碼。
- MP4 純音訊使用 .m4a 副檔名；其他音訊沿用串流副檔名。
- 可手動輸入儲存位置，預設 ~/Downloads；沒有資料夾選擇器。
- 網址改變後要求重新讀取；沒有選取格式時阻止下載。
- 原碼只有所有項目的同步下載及 ffmpeg 成功返回後才設定完成文字，並非在下載單一串流到 100% 時就完成。這個順序應保留；但仍缺少輸出檔有效性驗證。

## 已查證的問題與修正提案

| 現況／問題 | 選定方案後的修正方式 |
|---|---|
| 網路與 subprocess.run 在主執行緒，update_idletasks 無法維持完整操作回應 | 背景工作執行下載與合併；queue（安全傳送工作訊息的佇列）傳回事件；主視窗以 after（排程稍後執行）更新元件與動畫 |
| 沒有工具、網址與位置的完整事前檢查 | 驗證支援的 YouTube 網址、資料夾可寫性、隨附工具可執行性；保留原碼接受的網址型態，不假稱支援所有網站 |
| 固定 audio_itag / video_resolution_itag 檔名；ffmpeg -y 可覆蓋既有檔案 | 使用安全化標題、影片 ID、格式 ID 及衝突序號；每個工作獨立暫存目錄；合併到暫存輸出，驗證後移到最終路徑 |
| 讀取到零個格式也會顯示讀取完成 | 沒有可用格式時顯示原因與下一步，保持下載停用 |
| 缺少真實進度、重複操作鎖定 | 記錄工作中狀態並鎖定讀取、下載及相關輸入；讀取與合併無可靠總量時只顯示活動動畫 |
| 原始例外文字直接顯示給使用者 | 分類網路、無法讀取影片、路徑權限、磁碟空間及合併錯誤；繁體中文提示搭配可採取步驟，保留技術日誌供診斷 |
| 失敗可能留下暫存檔，成功刪除暫存檔失敗也會被當成下載失敗 | 分開記錄下載成果、合併成果與清理警告，不刪除使用者既有檔案 |
| 缺少 main 入口保護，匯入程式就會啟動視窗 | 拆分視窗與下載邏輯，增加 main 入口，便於測試與封裝 |
| entryURL / entrypath 接住 pack() 回傳值而非 Entry | 分開建立元件與排版，才能可靠停用、取得焦點及更新狀態 |

若多個勾選項目有部分失敗，顯示「部分成功」及各項結果，不顯示全部完成。僅所有選取項目下載、必要合併、輸出驗證均成功後，進入完成狀態。以 ffprobe 檢查音訊／影像串流與檔案可讀性；這不是完整解碼或觀看驗證。

## 已查證：工具與發佈文件

- 查詢當日 yt-dlp 最新穩定版頁面導向 2026.10.26；最低 Python 3.11。這是候選版本，不是已驗證相容組合。
  https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26
- FFmpeg / ffprobe 是外部可執行檔，不是安裝同名 Python 套件即可取代。yt-dlp-ejs 與支援的 JavaScript 引擎用於完整 YouTube 支援。
  https://github.com/yt-dlp/yt-dlp#dependencies
- yt-dlp 官方 EJS 文件列 Deno 最低 2.3.0，Node 最低 22.0.0；建議 Deno。EJS 解題元件也必須隨附，不能假設使用者已安裝或首次執行時一定能取得。
  https://github.com/yt-dlp/yt-dlp/wiki/EJS
- yt-dlp 原始碼／wheel 為 Unlicense；官方預包裝執行檔會包含其他授權，不能一概稱為 Unlicense。EJS 包含 MIT / ISC 元件。正式成品須逐項保留相應聲明。
  https://github.com/yt-dlp/yt-dlp#licensing
- FFmpeg 基本為 LGPL 2.1+；啟用 GPL 元件會改變授權條件，nonfree 組建不可直接當可再散佈版本。選定組建後須檢查編譯選項、所有相依元件、隨附授權與對應原始碼供應方式，不能只附一個網站連結便稱完成授權處理。
  https://ffmpeg.org/legal.html
- Deno 本體為 MIT，實際隨附的第三方元件仍需檢查。
  https://github.com/denoland/deno/blob/main/LICENSE.md
- PyInstaller 是把 Python 解譯器、程式與相依套件封裝成 App 的工具；其授權例外允許發佈商業 App，但仍須遵守各相依套件授權。
  https://pyinstaller.org/en/stable/license.html
- Apple 公證要求有效 Developer ID 簽署、Hardened Runtime、安全時間戳記等條件；隨附的外部執行檔也要納入簽署流程，完成後驗證公證票據。
  https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution

中文字使用 macOS 系統字體，不將系統字體檔複製進 App。正式像素素材另製作低解析度幀圖，以整數倍且不插值放大，測試 Retina 顯示；不把整張預覽當可互動介面。預覽圖內的柴犬為概念，不是已完成四狀態動畫。

- A 直覺直式面板：上方網址與位置，中間格式表，下方柴犬、進度及下載。操作由上往下；最接近原版，改造成本相對低。
- B 雙欄錄音機：左側設定與格式，右側柴犬、進度與下載。先左後右；工作狀態較醒目，需照顧欄寬與小視窗排版。
- C 三欄工作台：來源與位置／格式／下載與狀態三欄。由左至右操作；適合寬螢幕，小視窗需設定最小尺寸或重新排版。

三圖統一用待機、相同範例網址與 ~/Downloads；1080p / 720p MP4 加音訊及 M4A 128 kbps 僅為格式排版示意，尚未讀取，不保證任何影片提供。正式介面讀取前不會預先列出虛構格式。保留原版其他可用純音訊格式；圖中三列不代表僅支援三種格式。不加入播放、錄音、MP3 轉檔、歷史或無效旋鈕。

狀態流程：待機 → 讀取格式 → 可選格式 → 檢查 → 下載第 n 項的影像／音訊 → 必要合併 → 輸出驗證 → 下一項／全部完成。每個步驟都可能進入失敗或部分成功。

柴犬：待機坐著；工作戴耳機，以 after 排程動畫；完成搖尾巴；失敗困惑。始終搭配文字。下載百分比僅代表目前串流／項目，未知總量不用估算數字；合併中另顯示活動指示，不把下載 100% 當整體完成。磁帶和 LED 代表工作活動，不是音訊電平測量。

1. 建立獨立環境，鎖定 yt-dlp、EJS、Python、Tcl/Tk、PyInstaller 及外部工具版本與雜湊；進行真實下載／合併冒煙測試才宣稱組合相容。

3. 提供原始碼、素材、授權清單、圖示、版本資訊、打包設定與可重複步驟。
4. 製作 .app 後實測，再製作附 Applications 捷徑的拖曳安裝 DMG，掛載、拖曳到安裝位置並啟動測試。保留實際驗證記錄。
5. 測試：啟動、網址輸入、位置選擇、格式多選、真實下載／合併／檔案輸出、背景回應、重複點擊、動畫、未知進度、網路／無效網址／路徑／工具／合併錯誤與部分成功。
6. 沒有 Developer ID 憑證及公證認證時只能交付明確標記的未公證測試版；下載後可能受 Gatekeeper 阻擋，不宣稱所有 Mac 可直接開啟。
